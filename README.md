Project Description:
This project demonstrates the implementation of a task scheduling system using Java and Spring Boot. The system automates the execution of various jobs based on two scheduling strategies

1.Period of Time Scheduling: Executes tasks repeatedly at a fixed time interval (e.g., every day, every week, or every month).

2.Point of Time Scheduling: Executes tasks at a specific date and time (e.g., uploading documents at 9 PM, releasing project reports on a specific date).

Key Features:

1.Scheduled payroll and salary credit generation.

2.Automatic monthly email reminders.

3.Scheduled uploading of documents and releasing of reports.

4.Integration with JDK’s Timer and TimerTask classes.

5.Spring Boot-based scheduling support using spring-boot-starter.

Technologies Used:java,Meaven ,Spring Boot, Spring Schedular

Benefits:

Reduces manual effort in repetitive tasks.

Ensures timely execution of time-critical jobs.

Provides a reliable scheduling mechanism for enterprise applications.
